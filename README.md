
# RCC-Driver

This repository contains an RCC (Reset and Clock Control) driver for STM32, developed as part of the IEEE Alexandria University Student Branch, Embedded System Team.

## Technologies Used
- Microcontroller: STM32
- Development Environment: Eclipse
- Programming Language: C

## Functionality
The RCC driver manages the clock system of the STM32 microcontroller, including configuring clock sources (HSI, HSE, PLL, etc.), clock dividers, and peripheral clock enables. This driver enables precise control over the microcontroller's clock tree, optimizing system performance and power consumption.
